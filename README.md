# Демоверсия CRM Ростелеком ИТ Школы

Это опубликованная статическая сборка интерфейса для просмотра командой.
Данные на экранах демонстрационные. Исходные файлы кейса и персональные данные в этот репозиторий не включены.

Рабочий код, история изменений и инструкции для команды находятся в закрытом GitLab-проекте.

## Как проверить панель сотрудников

Откройте [панель сотрудников](https://marianna143.github.io/rostelecom-crm-demo/#/admin/employees). В ней можно:

- сменить одну из ролей: Пользователь / КАМ, Руководитель или Администратор платформы;
- назначить, сменить или снять ответственного по каждому проекту;
- добавить сотрудника как локальный черновик и выбрать для него роль.

Изменения видны при переходе между разделами в этой вкладке и сбрасываются после обновления страницы. Черновик не становится активным ответственным. Аккаунты и письма-приглашения не создаются, права доступа сервером здесь не проверяются.

## Вклад

Сценарий панели и продуктовые критерии сформулированы Марианной. Фронтенд-демо и его техническую реализацию подготовил Codex по её требованиям и обратной связи. API, постоянное хранение, приглашения и серверная проверка ролей остаются задачами backend-команды; ожидания описаны в закрытом GitLab-проекте.
