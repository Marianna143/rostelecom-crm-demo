# Демоверсия CRM Ростелеком ИТ Школы

Это опубликованная статическая сборка интерфейса для просмотра командой.
Данные на экранах демонстрационные. Исходные файлы кейса и персональные данные в этот репозиторий не включены.

Рабочий код, история изменений и инструкции для команды находятся в закрытом GitLab-проекте.

В демо есть экран **«Сотрудники»**: [открыть панель](https://marianna143.github.io/rostelecom-crm-demo/#/admin/employees). Он показывает список вымышленных сотрудников, роли, назначение ответственного за проект и форму локального черновика сотрудника.

Все изменения остаются в текущем просмотре браузера и пропадают после обновления. Аккаунты, права доступа и письма-приглашения не создаются: для рабочей версии нужны API и серверная проверка ролей.
