# Знаки вузов в демоверсии

Три файла используются только для визуального прототипа. Название вуза рядом со
знаком остаётся основным идентификатором; при ошибке изображения интерфейс
показывает буквенный аватар.

| Файл | Источник | Что изображено |
| --- | --- | --- |
| `bmstu.png` | <https://bmstu.ru/assets/images/favicon/apple-touch-icon.png> | Значок МГТУ им. Н. Э. Баумана |
| `spbstu.svg` | <https://ie.spbstu.ru/favicon/favicon.svg> | Знак СПбПУ Петра Великого |
| `urfu.png` | <https://urfu.ru/typo3conf/ext/urfu/Resources/Public/favicon/apple-touch-favicon.png> | Значок УрФУ |

Это изображения с сайтов вузов, а не утверждённый заказчиком набор брендовых
файлов. Перед выпуском рабочего продукта ответственный сотрудник должен
сверить актуальные версии и условия использования со сторонами. Фронтенд не
обращается к сайтам вузов при каждом показе: файлы лежат в самой сборке.
Для API и процесса пополнения изображений см.
[`docs/frontend/UNIVERSITY_EMBLEMS_BACKEND_TZ.md`](../../../../docs/frontend/UNIVERSITY_EMBLEMS_BACKEND_TZ.md).
